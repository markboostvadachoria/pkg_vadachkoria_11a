# Лабораторная 1, вариант 5

ColorLab.java — обычный интерфейс Swing. ColorModels.java — переводы CMYK, LAB и HSV через sRGB.

Цвет меняется полями (Enter или выход из поля), ползунками и палитрами. У каждой палитры можно выбрать оси X/Y. Допускаются точка и запятая. LAB использует D65, CMYK — учебную формулу без профиля принтера. При выходе LAB за охват sRGB появляется предупреждение, а цвет на экране обрезается. Исходные LAB при этом сохраняются.

Диапазоны: CMYK 0–100, L 0–100, a/b −128–127, H 0–360, S/V 0–100.
